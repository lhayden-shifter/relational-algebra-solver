# relational-algebra-solver
The Relational Algebra Framework Solver-an interactive tool that replaces procedural algebra with visual reasoning using triangles, inverse operations, and conceptual structure.

📘 Relational Algebra Framework Solver

Algebra shows the steps. This framework shows the thinking.

The Relational Algebra Framework Solver is an interactive tool that helps students solve equations using visual reasoning instead of memorized procedures.

Students use triangles (number bonds) to understand relationships between the whole and its parts, and apply inverse operations conceptually.

🚀 Live Demo

🎯 Purpose

Traditional algebra often relies on procedural steps that students forget.

This tool:

replaces “move it across the equals sign” thinking
builds conceptual understanding
reinforces structure over memorization
🧠 Core Idea

Every equation is a relationship between:

Whole (top circle)
Parts (bottom circles)

Students solve by:

Building (combining parts)
Breaking (undoing the whole)
Revealing (isolating the unknown)
🔺 Visual Model

Each step is represented as a triangle:

        Whole
       /     \
   Part     Part
🔄 Operation Rules
Relationship	Build	Break
Addition	+	−
Subtraction	−	+
Multiplication	×	÷
Division	÷	×
✨ Features
✅ Step-by-step interactive solving
✅ Visual triangle model (whole ↔ parts)
✅ Student decision-making (choose operation)
✅ Immediate feedback
✅ Arch visualization showing results
✅ No “swap steps” (preserves equation structure)
✅ Supports multiple equation types
📊 Supported Equation Types
7 + s = 10
s + 3 = 10
2(w + 3) = 26
3x = 12
w/5 - 7 = 3
1/2(5 + x) = 7.5
7 + s + 2 = 15
7 + (s - 3) = 10
