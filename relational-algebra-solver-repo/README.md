# Relational Algebra Framework Solver

A classroom-ready interactive solver based on the Relational Algebra Framework.

## Files
- `index.html` — main app file for GitHub Pages

## Publish with GitHub Pages
1. Create a new GitHub repository named `relational-algebra-solver`
2. Upload the contents of this folder
3. In GitHub, open **Settings** → **Pages**
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save
6. GitHub will give you a public link
